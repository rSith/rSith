## 👩‍💻 About Me

I'm a **B.Sc. (Hons/Special) Computer Science** student at the **Faculty of Applied Sciences, Wayamba University of Sri Lanka**. My path started in Mathematics & Statistics and Computer Science (CMIS), which gave me a strong quantitative foundation. Now I'm building on it with a focus on machine learning, data, and software engineering.

- 🔭 **Currently working on:** ML Specialization labs, Python foundations, and a job market analyzer using the Adzuna API
- 🌱 **Currently learning:** Machine Learning, Mathematics for ML, MLOps, and AI-assisted software engineering
- 💬 **Ask me about:** Python, Java, MySQL, statistics, and getting started with ML
- 🎯 **Goal:** become an AI/ML Engineer, with a strong interest in Data Science and Data Analytics
- ⚡ **Fun fact:** I come from a background in 3D animation & VFX and Building Management Systems, and I'm now channelling that into AI/ML
